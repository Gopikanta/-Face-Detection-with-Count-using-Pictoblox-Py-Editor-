👤 Face Detection with Count using Pictoblox (Py Editor)

📌 Overview

This project uses Pictoblox’s Python Editor with the Face Detection extension to detect faces in real-time through a webcam.
It not only detects faces but also counts the number of faces visible and displays the count on the screen using a sprite character.

✨ Features

Real-time face detection using webcam

Counts the number of faces detected

Displays the result on a sprite (Tobi)

Handles cases when the camera is not ready

🛠️ Requirements

Pictoblox

 (Py Editor mode)

Face Detection extension enabled

Webcam connected to your system

▶️ How to Run

Open Pictoblox in Py Editor mode.

Import the Face Detection extension.

Enter the code.

Run the project with your webcam connected.

The sprite will display whether faces are detected and show the number of faces.

Classroom or event attendance system
